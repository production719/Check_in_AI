# เว็บเช็คชื่อคลาส Claude AI — สำหรับเอาขึ้นเซิร์ฟเวอร์

**เวอร์ชันปัจจุบัน: v1.2.0** · เว็บไซต์: https://production719.github.io/Check_in_AI/ · ประวัติเวอร์ชัน: [CHANGELOG.md](CHANGELOG.md)

## การอัปเดตเวอร์ชัน
1. แก้ไฟล์ `index.html` ตามต้องการ
2. เพิ่มรายการใหม่ไว้ **บนสุด** ของ `CHANGELOG` ใน `index.html` (เลขเวอร์ชันบนเว็บจะเปลี่ยนตามอัตโนมัติ) และใน `CHANGELOG.md`
3. Commit ขึ้น GitHub — GitHub Pages จะอัปเดตเว็บเองภายใน 1–2 นาที

ตั้งเลขแบบ `MAJOR.MINOR.PATCH`: แก้บั๊กเล็ก → เพิ่มเลขท้าย (1.2.1), เพิ่มฟีเจอร์ → เลขกลาง (1.3.0), เปลี่ยนใหญ่ → เลขหน้า (2.0.0)

## ไฟล์
- `index.html` — ตัวเว็บทั้งหมด (ไฟล์เดียว) อัปโหลดขึ้นเซิร์ฟเวอร์ได้เลย เช่น hosting ทั่วไป, GitHub Pages, Netlify, Vercel
- `google-apps-script.gs` — โค้ดสำหรับส่งข้อมูลเช็คชื่อเข้า Google Sheets (ไม่บังคับ)

## ตั้งค่า (แก้ที่ด้านบนของสคริปต์ใน index.html)
| ค่า | ความหมาย |
|---|---|
| `GOOGLE_SCRIPT_URL` | URL ของ Apps Script Web app (ดูวิธีในไฟล์ .gs) — เว้นว่าง = ไม่ส่งไป Sheets |
| `ADMIN_PIN` | รหัสเข้าโหมดผู้สอน (ค่าเริ่มต้น `1234` — ควรเปลี่ยน) |
| `SEED_ROSTER` | รายชื่อเริ่มต้น 23 คน ใช้ตอนเปิดเว็บครั้งแรกในแต่ละเครื่อง |

## การใช้งาน
- ผู้เรียน: เปิดเว็บ → แตะชื่อ → เซ็น → ยืนยัน
- ผู้สอน: เปิด `https://โดเมนของคุณ/#admin` แล้วใส่ PIN เพื่อนำเข้า CSV/Excel, ตั้งเวลาเริ่มคลาส, ดาวน์โหลด CSV

## ข้อควรรู้
- เวอร์ชันนี้เก็บข้อมูลไว้ใน **เบราว์เซอร์ของเครื่องที่เปิด** เหมาะกับการตั้งแท็บเล็ตเครื่องเดียวหน้าห้อง
  ถ้าตั้ง `GOOGLE_SCRIPT_URL` ไว้ ทุกการเช็คชื่อจะถูกส่งเข้า Google Sheet ด้วย จึงรวมข้อมูลจากหลายเครื่องได้
- PIN อยู่ในโค้ดหน้าเว็บ จึงกันได้แค่ผู้ใช้ทั่วไป ไม่ใช่ระบบความปลอดภัยเต็มรูปแบบ
- เวอร์ชันบน Claude (ลิงก์ artifact) เป็นฐานข้อมูลออนไลน์แยกจากเวอร์ชันนี้
